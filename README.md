# KG2025 – Territory and Transport in Trentino

This repository contains the complete development of a **Knowledge Graph (KG) project** carried out following the **iTelos methodology**, within the context of the *Knowledge Graphs* course (University of Trento).

The goal of the project is to model and represent information related to **territory, transport, and associated services in the Trentino region**, by integrating multiple open data sources and reference ontologies.

---

##  Repository Structure

The repository is organized according to the phases of the iTelos methodology:

- **Phase 1 – Purpose Definition**  
  Definition of the KG purpose, scenarios, personas, and competency questions.

- **Phase 2 – Language Definition**  
  Identification and normalization of domain concepts, terms, and properties.

- **Phase 3 – Knowledge Definition**  
  Construction of the teleology and alignment with reference ontologies (e.g., OpenStreetMap, Schema.org).

- **Phase 4 – Entity Definition**  
  Integration of the knowledge layer and the data layer, entity definition, and dataset mapping.

- **Metadata**  
  Definition of metadata related to the project, knowledge resources, datasets, and the final Knowledge Graph.

- **Evaluation**  
  Evaluation of the final Knowledge Graph using structural metrics and the execution of competency queries.

- **Documentation**  
  Additional documentation and supporting materials for the project.

---

##  Data Sources

The project primarily uses open data extracted from **OpenStreetMap**, as well as public datasets related to:
- Cycling routes
- Hiking trails
- Ski slopes
- Ski rental shops
- Restaurants
- Hotels
- Viewpoints

Detailed descriptions and download links for each dataset are provided in the **Metadata** section.

---

##  Methodology

The project strictly follows the **iTelos methodology**, covering all phases from purpose definition to the evaluation of the final Knowledge Graph.
